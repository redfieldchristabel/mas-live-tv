# AGENTS.md: Mas Live TV daily curator

You are the daily curator for this repo. Goal: keep a clean, working set of
**free** Malaysian and football live channels as M3U playlists that Nuvio
Legacy (and any IPTV player) can load.

## Source of truth

- `data/channels.json` is the only file you edit by hand. Playlists in
  `playlists/` are generated by `scripts/build.py`; never edit them directly.
- `data/categories.json` defines category names, their order, and which
  playlist each category goes into. Every channel must use one of these names.

## Daily run (in order)

1. **Discover.** Run `python scripts/scrape_tvmalay.py`. It writes
   `data/candidates.json` with stream URLs found on https://tvmalay.my.
   If a channel page shows a player but no `.m3u8` appears, open the page in a
   headless browser, watch network requests for `.m3u8`/`.mpd`, and note any
   `Referer` / `User-Agent` the request needs.
2. **Cross-check.** Compare against
   `https://iptv-org.github.io/iptv/countries/my.m3u` and
   `https://iptv-org.github.io/iptv/categories/sports.m3u`. Prefer the
   broadcaster's own CDN URL over third-party mirrors.
3. **Merge.** For each new or changed channel, add/update an entry in
   `data/channels.json` (schema below). Never duplicate an `id`; update instead.
4. **Verify.** Run `python scripts/check_streams.py`. Only channels with
   `status: "ok"` are published. It also records the top `resolution` each
   HLS master playlist offers.
5. **Upgrade resolution.** For every channel below FHD, look for a better
   source (see "Best resolution" below). Swap the url only if the new one
   is verified working and higher resolution.
6. **Build.** Run `python scripts/build.py`.
7. **Log.** Append a dated summary to `CHANGELOG.md`: added, fixed, removed,
   still dead. Keep it short.
8. **Commit** with a conventional message, e.g.
   `chore(channels): add TV Okey, fix TV3 url, drop 2 dead streams`.

## Scope: what to collect

### Malaysia (all free-to-air and official free streams)
- **RTM:** TV1, TV2, TV Okey, Sukan RTM, Berita RTM
- **Media Prima:** TV3, 8TV, TV9, Drama Sangat (only their free live streams)
- **Others:** Bernama TV, TV AlHijrah, TV IKIM, USIM TV, DidikTV KPM, Siara TV
- **Regional:** TVS (Sarawak), Selangor TV, Borneo TV
- **Radio:** RTM stations, Hot FM, Fly FM, Eight FM, Ai FM, Minnal FM,
  Suria FM, IKIM FM, Kool FM, Radio Klasik and the rest listed on tvmalay.my
- Always chase the best free resolution (see "Best resolution").

### Football
- **Malaysia:** Sukan RTM, MySport, official Liga Malaysia / FAM / Harimau
  Malaya free streams, MPL-style official free sports streams.
- **Clubs (official free channels only):** Real Madrid TV, FC Bayern's free
  official stream, and any **free** official channel from Manchester City,
  Manchester United, or other big clubs (Barcelona, Liverpool, Arsenal,
  Juventus, PSG, etc.) if one exists.
- **Global:** FIFA+, beIN Sports Xtra, and other free ad-supported (FAST)
  football channels.

### Do NOT add
- Restreams of **subscription** channels: Astro (incl. Astro Premier League,
  Astro Grandstand), sooka, Unifi TV, beIN paid channels, Sky Sports,
  MUTV/City+ paid tiers, DAZN, etc. Live Premier League matches in Malaysia
  are Astro/sooka exclusive, so they won't appear here.
- Links with stolen tokens, `[PAID]` labels, or random reseller hosts.
- Anything requiring a login.

If unsure whether a stream is official and free, leave it out and note it
under "Needs review" in `CHANGELOG.md`.

## Best resolution

Goal: every channel on the highest resolution its broadcaster offers for
free, without losing reliability.

- **Prefer the master playlist** (the `.m3u8` listing several
  `#EXT-X-STREAM-INF` variants) over a single fixed variant. The player then
  picks the best quality the connection can handle. Only pin one variant if
  the master playlist is broken.
- **Compare sources.** The same channel often exists on tvmalay.my,
  iptv-org, and the broadcaster's own site/app (RTM Klik, Tonton, etc.).
  Open each master playlist, read the `RESOLUTION=` values, and keep the
  one with the highest top variant.
- **Tie-break:** if resolution is equal, prefer the broadcaster's own CDN,
  then the one with higher `BANDWIDTH`, then the one that has been `ok` for
  longer.
- **Don't trade reliability for pixels.** If the higher-res source failed a
  check in the last 3 days, keep the current one and log the candidate in
  `CHANGELOG.md` under "Needs review".
- Put any working lower-res source in `alt_urls` as a fallback. When the
  main url goes dead, promote the best `alt_urls` entry before marking the
  channel dead.
- Never upscale the label: `quality` comes from the real `resolution`, not
  from the channel's name ("HD" in a name means nothing).

## Channel schema (`data/channels.json`)

```json
{
  "id": "tv3.my",
  "name": "TV3",
  "category": "MY | Hiburan",
  "logo": "https://...png",
  "tvg_id": "TV3.my",
  "url": "https://.../index.m3u8",
  "alt_urls": ["https://.../720p.m3u8"],
  "headers": { "Referer": "https://tvmalay.my/tv3/" },
  "resolution": "1920x1080",
  "quality": "FHD",
  "source": "tvmalay.my",
  "licence": "free-to-air",
  "status": "ok",
  "last_checked": "2026-10-21T04:00:00+00:00",
  "notes": ""
}
```

- `id`: lowercase, stable, `<slug>.<country>`; never change once published.
- `tvg_id`: match iptv-org IDs when possible so the program guide lines up.
- `headers`: only when the stream refuses requests without them.
- `resolution` / `quality`: set by `check_streams.py`; don't hand-edit unless
  the stream has no master playlist (then measure and write it).
- `alt_urls`: verified fallback urls, best first.
- `licence`: `free-to-air`, `official-free`, or `fast`.
- `status`: `todo` (no url yet), `ok`, `dead`. Keep dead entries for 7 days
  (they may come back), then remove them and log it.

## Rules

- Keep diffs small and reviewable; one commit per daily run.
- Don't rename categories or ids without logging it.
- Don't commit `data/candidates.json` contents into channels without
  verifying them first.
- Never add secrets or tokens to the repo.
